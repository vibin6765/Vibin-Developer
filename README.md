# Vibin — Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — navy-and-gold theme and responsive styling
- `script.js` — mobile navigation and hero text animation
- `vibin-profile.jpeg` — uploaded profile portrait
- `Vibin_Resume.pdf` — uploaded resume

Keep all five files in the same folder. The HTML uses relative paths to the photo and PDF.

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click and choose **Open with Live Server** (if installed), or open the HTML file in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `vibin-portfolio`.
2. Upload all five files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.
